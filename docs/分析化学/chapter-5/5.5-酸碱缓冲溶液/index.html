      当 pH<6\text{pH} < 6pH<6 时，可忽略 [OHX−][\ce{OH-}][OHX−]

      [HX+]=Kac(HA)−[HX+]c(AX−)+[HX+] [\ce{H+}] = K_a \frac{c(\ce{HA}) - [\ce{H+}]}{c(\ce{A-}) + [\ce{H+}]} [HX+]=Ka​c(AX−)+[HX+]c(HA)−[HX+]​

      当 pH>8\text{pH} > 8pH>8 时，可忽略 [HX+][\ce{H+}][HX+]

      [HX+]=Kac(HA)+[OHX−]c(AX−)−[OHX−] [\ce{H+}] = K_a \frac{c(\ce{HA}) + [\ce{OH-}]}{c(\ce{A-}) - [\ce{OH-}]} [HX+]=Ka​c(AX−)−[OHX−]c(HA)+[OHX−]​

      缓冲容量 (buffer capacity)

      缓冲容量 (β\betaβ)

      使 1 L1\ \text{L}1 L 缓冲溶液的 pH 增加 dpH 单位所需的强碱的量 db (mol)\text{d}b\ (\text{mol})db (mol)，或是使 1 L1\ \text{L}1 L 缓冲溶液的 pH 减少 dpH 单位所需的强酸的量 da (mol)\text{d}a\ (\text{mol})da (mol)。

      β=dbdpH=−dadpH \beta = \frac{\text{d}b}{\text{dp}\ce{H}} = -\frac{\text{d}a}{\text{dp}\ce{H}} β=dpHdb​=−dpHda​

      现以 HB\ce{HB}HB-BX−\ce{B-}BX− 体系为例，设缓冲溶液的总浓度为 ccc，其中 BX−\ce{B-}BX− 的浓度为 bbb，即相当于 c(mol⋅L−1)HBc(\mathrm{mol \cdot L^{-1}}) \ce{HB}c(mol⋅L−1)HB 与 b(mol⋅L−1)OHX−b(\mathrm{mol \cdot L^{-1}}) \ce{OH-}b(mol⋅L−1)OHX− 的混合溶液。

      HB + bOH = B- + H2O

      质子守恒

      b+[HX−]=[BX−]+[OHX−] b + [\ce{H-}] = [\ce{B-}] + [\ce{OH-}] b+[HX−]=[BX−]+[OHX−]

      所以

      b=−[HX+]+Kw[HX+]+cKa[HX+]+Ka b = -[\ce{H+}] + \frac{K_w}{[\ce{H+}]} + \frac{c K_a}{[\ce{H+}] + K_a} b=−[HX+]+[HX+]Kw​​+[HX+]+Ka​cKa​​

      于是

      dbdpH=−1−Kw[HX+]2−cKa([HX+]+Ka)2 \frac{\text{d}b}{\text{dp}\ce{H}} = -1 - \frac{K_w}{[\ce{H+}]^2} - \frac{c K_a}{([\ce{H+}] + K_a)^2} dpHdb​=−1−[HX+]2Kw​​−([HX+]+Ka​)2cKa​​

      又

      pH=−lg⁡[HX+] \text{p}\ce{H} = - \lg [\ce{H+}] pH=−lg[HX+]

      则

      dpHd[HX+]=−1(ln⁡10)[HX+] \frac{\text{dp}\ce{H}}{\text{d}[\ce{H+}]} = - \frac{1}{(\ln 10) [\ce{H+}]} d[HX+]dpH​=−(ln10)[HX+]1​

      那么

      β=dbdpH=dbd[HX+]d[HX+]dpH=(ln⁡10)([HX+]+[OHX−]+cKa[HX+]([HX+]+Ka)2) \beta = \frac{\text{d}b}{\text{dp}\ce{H}} = \frac{\text{d}b}{\text{d}[\ce{H+}]} \frac{\text{d}[\ce{H+}]}{\text{dp}\ce{H}} = (\ln 10) \left([\ce{H+}] + [\ce{OH-}] + \frac{cK_a [\ce{H+}]}{([\ce{H+}] + K_a)^2} \right) β=dpHdb​=d[HX+]db​dpHd[HX+]​=(ln10)([HX+]+[OHX−]+([HX+]+Ka​)2cKa​[HX+]​)

      当 [HX+][\ce{H+}][HX+] 和 OHX−\ce{OH-}OHX− 都较小时

      β=(ln⁡10)cKa[HX+]([HX+]+Ka)2 \beta = (\ln 10) \frac{cK_a [\ce{H+}]}{([\ce{H+}] + K_a)^2} β=(ln10)([HX+]+Ka​)2cKa​[HX+]​

      则

      dβd[HX+]=(ln⁡10)cKaKa−[HX+]([HX+]+Ka)3=0 \frac{\text{d}\beta}{\text{d}[\ce{H+}]} = (\ln 10) c K_a \frac{K_a - [\ce{H+}]}{([\ce{H+}] + K_a)^3} = 0 d[HX+]dβ​=(ln10)cKa​([HX+]+Ka​)3Ka​−[HX+]​=0

      [HX+]=Ka [\ce{H+}] = K_a [HX+]=Ka​

      选择缓冲溶液的原则：

      1. 缓冲溶液对分析过程没有干扰
      2. 所需控制的 pH 应在缓冲溶液的缓冲范围之内。如果缓冲溶液是由弱酸及其共轭碱组成的，则 pKa\text{p}K_apKa​ 应尽量与所需控制的 pH\text{p}\ce{H}pH 一致。
      3. 缓冲溶液应有足够的缓冲容量，通常缓冲组分的浓度在 0.01∼1.00 mol⋅L−10.01 \sim 1.00\ \mathrm{mol \cdot L^{-1}}0.01∼1.00 mol⋅L−1 之间。

      实际可采用多种酸和碱构成的缓冲溶液，以得到广泛的 pH 范围。

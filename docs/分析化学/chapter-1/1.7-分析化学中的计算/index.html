      标准溶液浓度的表示方法

      标准溶液浓度常用物质的量浓度表示

      Def. (物质的量浓度) 物质 B\ce{B}B 的物质的量浓度指单位提及溶液中所含溶质 B\ce{B}B 的物质的量，用符号 cBc_\ce{B}cB​ 表示

      B=nBV \ce{B} = \frac{n_\ce{B}}{V} B=VnB​​

      式中，nBn_\ce{B}nB​ 表示溶液中溶质 B\ce{B}B 的物质的量，单位为 mol\mathrm{mol}mol 或 mmol\mathrm{mmol}mmol；VVV 为溶液的体积，单位可以为 m3,dm3\mathrm{m^3, dm^3}m3,dm3 等。

      在分析化学中，最常用的体积单位为 L\mathrm{L}L 和 mL\mathrm{mL}mL，浓度 cBc_\ce{B}cB​ 的常用单位为 mol⋅L−1\mathrm{mol \cdot L^{-1}}mol⋅L−1。

      Rem. 表示物质的量浓度时，必须指明基本单元。一般的，有

      cbaB=abcB c_{\frac{b}{a}\ce{B}} = \frac{a}{b} c_\ce{B} cab​B​=ba​cB​

      在生产单位的例行分析中，为了简化计算，常用滴定度表示标准溶液的浓度

      Def. (滴定度, titer) 滴定度是指每毫升滴定剂溶液相当于被测物质的质量（克或毫克）。

      Eg. 例如

      TFe/KX2CrX2XOX7=0.005000g⋅mL−1 T_{\ce{Fe}/\ce{K_2Cr_2_O_7}} = 0.005000 \mathrm{g \cdot mL^{-1}} TFe/KX2​CrX2​XO​X7​​=0.005000g⋅mL−1

      表示每毫升 KX2CrX2OX7\ce{K_2Cr_2O_7}KX2​CrX2​OX7​ 标准溶液恰好能与 0.005000g FeX2+0.005000 \mathrm{g}\ \ce{Fe^{2+}}0.005000g FeX2+ 反应。

      如果滴定中消耗该 KX2CrX2OX7\ce{K_2Cr_2O_7}KX2​CrX2​OX7​ 标准溶液 21.50 mL，则被滴定溶液中铁的质量为

      mFe=0.005000g⋅mL−1×21.50mL=0.1075g m_\ce{Fe} = 0.005000 \mathrm{g \cdot mL^{-1}} \times 21.50 \mathrm{mL} = 0.1075 \mathrm{g} mFe​=0.005000g⋅mL−1×21.50mL=0.1075g

      滴定度与物质的量浓度可以换算。

      Eg. 基于 1 CrX2OX7X2−\ce{1 Cr_2O_7^{2-}}1CrX2​OX7​X2− 与 6 FeX2+\ce{6 Fe^{2+}}6FeX2+ 的滴定反应，上例中每升 KX2CrX2OX7\ce{K_2Cr_2O_7}KX2​CrX2​OX7​ 溶液中 KX2CrX2OX7\ce{K_2Cr_2O_7}KX2​CrX2​OX7​ 物质的量，即它的浓度为

      cKX2CrX2OX7=TFe/KX2CrX2OX7×103mL⋅L−1MFe×6=0.01492mol⋅L−1 c_\ce{K_2Cr_2O_7} = \frac{T_{\ce{Fe}/\ce{K_2Cr_2O_7}} \times 10^3 \mathrm{mL \cdot L^{-1}}}{M_\ce{Fe} \times 6} = 0.01492 \mathrm{mol \cdot L^{-1}} cKX2​CrX2​OX7​​=MFe​×6TFe/KX2​CrX2​OX7​​×103mL⋅L−1​=0.01492mol⋅L−1

      滴定剂与被滴定物质之间的计量关系

      在直接滴定法中，设滴定剂 T\ce{T}T （标准溶液）与贝蒂顶物质 B\ce{B}B 有下列化学反应

      t T+b B = ⁣= ⁣= c C+d D \ce{tT + bB =\!=\!= cC + dD} tT+bB === cC+dD

      当上述滴定反应到达化学计量点时，滴定剂 T\ce{T}T 的物质的量 nTn_\ce{T}nT​ 与被测物质 B\ce{B}B 的物质的量 nBn_\ce{B}nB​ 之间的比

      nT:nB=t:bn_\ce{T} : n_\ce{B} = t : bnT​:nB​=t:b

      即

      nB=btnT 或 nT=tbnTn_\ce{B} = \frac{b}{t} n_\ce{T} \text{ 或 } n_\ce{T} = \frac{t}{b} n_\ce{T} nB​=tb​nT​ 或 nT​=bt​nT​

      其中 bt\frac{b}{t}tb​ 和 tb\frac{t}{b}bt​ 称为化学计量数比，简称计量比

      Rem.

      n15KMnOX4=n12HX2CX2OX4⇔5nKMnOX4=2nHX2CX2OX4 n_{\frac{1}{5} \ce{KMnO_4}} = n_{\frac{1}{2} \ce{H_2C_2O_4}} \Leftrightarrow 5n_{\ce{KMnO_4}} = 2n_{\ce{H_2C_2O_4}} n51​KMnOX4​​=n21​HX2​CX2​OX4​​⇔5nKMnOX4​​=2nHX2​CX2​OX4​​

      在置换滴定法和简介滴定法中，应从总的反应中找出试剂参加反应的物质的物质的量之间的关系。

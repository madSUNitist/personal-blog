      总体平均值 (population mean)

      μ:=lim⁡n→∞1n∑i=1nxi \mu := \lim_{n \to \infty} \frac{1}{n} \sum_{i=1}^n x_i μ:=n→∞lim​n1​i=1∑n​xi​

      平均值的标准偏差

      抽 m 个样本，每个样本做 n 次采样，得到 n 个均值，此时对于有限次测量，有

      sxˉ=sn s_{\bar{x}} = \frac{s}{\sqrt{n}} sxˉ​=n​s​

      或者对于无限次测量，有

      σxˉ=σn \sigma_{\bar{x}} = \frac{\sigma}{\sqrt{n}} σxˉ​=n​σ​

      同样有

      δxˉ=δn \delta_{\bar{x}} = \frac{\delta}{\sqrt{n}} δxˉ​=n​δ​

      和

      dˉxˉ=dˉn \bar{d}_{\bar{x}} = \frac{\bar{d}}{\sqrt{n}} dˉxˉ​=n​dˉ​

      少量实验数据的统计处理

      ttt-分布曲线

      ttt 置信因子：

      t:=xˉ−μsxˉ t := \frac{\bar{x} - \mu}{s_{\bar{x}}} t:=sxˉ​xˉ−μ​

      ttt-分布的纵坐标为概率密度，横坐标为统计量 ttt。

      自由度 (defree of freedom, fff, f=n−1f = n - 1f=n−1) 趋于正无穷时，ttt-分布趋于正态分布。

      置信度 (confidence, PPP) 表示在某一 ttt 值时，测定值落入 (μ±ts)(\mu \pm t s)(μ±ts) 范围内的概率。

      显著性水平 (siginificance level, α\alphaα, α=1−P\alpha = 1 - Pα=1−P) 是测定值落在此范围之外的概率。

      平均值的置信区间

      由

      μ=x±uσ \mu = x \pm u \sigma μ=x±uσ

      有

      μ=xˉ±uσn \mu = \bar{x} \pm \frac{u\sigma}{\sqrt{n}} μ=xˉ±n​uσ​

      对于少量数据，有

      μ=xˉ±tsn \mu = \bar{x} \pm \frac{t s}{\sqrt{n}} μ=xˉ±n​ts​

      这实际上应当理解为 [xˉ−tsn,xˉ+tsn][\bar{x} - \frac{t s}{\sqrt{n}}, \bar{x} + \frac{t s}{\sqrt{n}}][xˉ−n​ts​,xˉ+n​ts​] 包含 μ\muμ 的概率是 tα,ft_{\alpha, f}tα,f​，而非 μ\muμ 落在该区域内的概率，因为 μ\muμ 是客观存在的确定值。

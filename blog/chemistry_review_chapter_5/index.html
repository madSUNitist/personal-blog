      氢原子光谱在可见光区有 4 条明显的谱线，通常用 Hα,Hβ,Hγ,Hδ\mathrm{H_\alpha, H_\beta, H_\gamma, H_\delta}Hα​,Hβ​,Hγ​,Hδ​ 表示。

      巴尔末 (Balmer) 公式

      λ=Bn2n2−4 \lambda = B \frac{n^2}{n^2 - 4}λ=Bn2−4n2​

      里德伯 (Rydberg) 公式

      σ=RH(1n12−2n22) \sigma = R_\text{H} \left(\frac{1}{n_1^2} - \frac{2}{n_2^2}\right) σ=RH​(n12​1​−n22​2​)

      普朗克的量子论

      普朗克 (Planck) 认为在微观领域能量是不连续的，物质吸收或放出的能量总是一个最小的能量单位的整倍数。

      爱因斯坦 (Einstein) 光电效应

      E=hν E = h \nuE=hν

      波尔理论

      波尔 (Bohr) 氢原子光谱

      核外电子在特定的原子轨道上运动，轨道具有固定的能量 EEE

      E=−E1n2E = -\frac{E_1}{n^2}E=−n2E1​​

      其中 E1=13.6 eVE_1 = 13.6\,\mathrm{eV}E1​=13.6eV

      波尔 (Bohr) 氢原子光谱（推论）

      放出的光子的能量满足：

      hν=E2−E2 h\nu = E_2 - E_2 hν=E2​−E2​

      于是

      ν=−E1h(1n12−1n22) \nu = -\frac{E_1}{h}\left(\frac{1}{n_1^2} - \frac{1}{n_2^2}\right) ν=−hE1​​(n12​1​−n22​1​)

      其中 E1=13.6 eVE_1 = 13.6 \,\mathrm{eV}E1​=13.6eV

      微观粒子的波粒二象性

      量子数的概念

      主量子数 nnn

      1. 主量子数 nnn 的取值为 1,2,3,4,5,6,⋯1, 2, 3, 4, 5, 6, \cdots1,2,3,4,5,6,⋯ 正整数，在光谱学中分别用大写字母 K,L,M,N,O,P,⋯\mathrm{K, L, M, N, O, P, \cdots}K,L,M,N,O,P,⋯ 代表
      2. 主量子数 nnn 决定了电子的能量 EEE
        电子所在原子种类
        氢原子和类氢离子 核外电子的能量只取决于 nnn，nnn 越大，EEE 越高
        多电子原子 除了取决于 nnn 以外，还与其他因素有关
      3. 描述原子中电子出现概率最大区域离核远近

      角量子数 lll

      1. 角量子数 lll 的取值为 0,1,2,3,4,...,(n−1)0, 1, 2, 3, 4, ..., (n - 1)0,1,2,3,4,...,(n−1)，对应的光谱学符号为 s, p, d, f, g 等。
      2. 角动量 MMM
      ∣M∣=h2πl(l+1) \left|M\right| = \frac{h}{2\pi} \sqrt{l(l + 1)} ∣M∣=2πh​l(l+1)​

      3. 在多电子原子中，电子的能量 EEE 不仅取决于 nnn，而且与 lll 有关。nnn 相同，lll 不同的原子轨道，角量子数 lll 越大的，能量 EEE 越大 4. 角量子数 lll 决定原子轨道的形状。

      磁量子数 mmm

      1. mmm 的取值为 0,±1,±2,±3,⋯ ,±l0, \pm 1, \pm 2, \pm 3, \cdots, \pm l0,±1,±2,±3,⋯,±l，共有 (2l+1) (2l + 1) (2l+1) 个值。
      2. 角动量 MMM（矢量）在 zzz 轴上的分量 MzM_zMz​
      Mz=mh2πM_z = m \frac{h}{2 \pi} Mz​=m2πh​

      3. 磁量子数 mmm 决定原子轨道在核外空间中的分布方向

      自旋磁量子数 msm_\text{s}ms​

      1. msm_\text{s}ms​ 的取值只有两个，即 m=±1/2m = \pm 1/2m=±1/2。

      电离能 (ionisation energy)

      电离能

      电离能是指一个基态的气态原子失去一个电子，成为一价气态阳离子所需的最低能量，通常用符号 I I I 表示，单位为 kJ⋅mol−1 \mathrm{kJ \cdot mol^{-1}} kJ⋅mol−1 或 eV \mathrm{eV} eV。第一电离能 I1 I_1 I1​ 最为常见，它反映了原子失去电子的难易程度，是衡量元素金属性的重要指标。

      电子亲和能 (electron affinity)

      电子亲和能

      电子亲和能是指一个基态的气态原子获得一个电子，成为一价气态阴离子时所释放的能量，通常用符号 E1 E_1 E1​ 表示。它反映了原子获得电子的能力，数值越大（放热越多），表示原子越容易得到电子。

      电负性 (electronegativity)

      Pauling 经验电负性

      Pauling 经验电负性

      基于两种元素形成的键能与它们各自同种原子键能的几何平均值之间的差值进行计算。鲍林标度是最早且应用最广的电负性标度，规定氟的电负性为 4.0（后修正为 3.98），以此作为参照基准。

      Mulliken 电负性

      Mulliken 电负性

      元素的第一电离能 I1 I_1 I1​ 与其第一电子亲和能 E1 E_1 E1​ 之和的算术平均值：

      χ=I1+E12 \chi = \frac{I_1 + E_1}{2} χ=2I1​+E1​​

      该标度基于原子的绝对能量参数，具有更明确的物理意义。

      Allen 光谱电负性

      Allen 光谱电负性

      元素自由原子基态价层电子的平均单电子能量，经缩放因子转换后的数值。对于主族元素，其计算公式为

      χspec=2.3013.60×mϵp+nϵsm+n \chi_{\text{spec}} = \frac{2.30}{13.60} \times \frac{m \epsilon_\text{p} + n \epsilon_\text{s}}{m + n} χspec​=13.602.30​×m+nmϵp​+nϵs​​

      其中 ϵp \epsilon_\text{p} ϵp​、ϵs \epsilon_\text{s} ϵs​ 为光谱测得的轨道电子能量，m m m、n n n 为对应轨道电子数。该标度完全基于原子光谱数据。
